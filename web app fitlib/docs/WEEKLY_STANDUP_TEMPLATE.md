## ⏰ How to Use This Template

**Every Friday at 5 PM (takes ~10 minutes):**

1. Copy this template
2. Fill out each section while reviewing the week
3. Compare metrics vs. targets (use green/yellow/red status)
4. Identify 3 priorities for next week (realistic, not wishful)
5. Note any blockers that need solving
6. Save to GitHub (`docs/standups/standup_YYYY-MM-DD.md`)

**At end of month:**
- Review all 4 weekly standups
- Note patterns (what consistently works/fails)
- Adjust next month accordingly

**Every quarter:**
- Review all 13 weekly standups
- Compare actual vs. planned
- Update ROADMAP.md with learnings

---

## 💡 Tips for Honest Standups

✅ **Be realistic about time spent**
- If something took 6 hours, say 6 hours
- "Under the radar" work still counts (debugging, admin)

✅ **Celebrate small wins**
- Fixed one bug = win
- Got first user feedback = win
- Found one new idea = win

✅ **Don't hide blockers**
- Blockers get solved, not buried
- The sooner you name it, the sooner you fix it

✅ **Use data, not feelings**
- "Users love the graph" (good) vs. "I think it's good" (vague)
- Check Firebase/Algolia for actual numbers

✅ **Stay sustainable**
- If hours are regularly >8, something needs to change
- Burnout helps nobody
