# Lovable AI Website Builder Prompt

## 🎯 **Perfect Prompt for Lovable**

```
Create a cyberpunk terminal-style fitness knowledge database website with the following specifications:

CORE CONCEPT:
Build a comprehensive fitness and exercise science library that feels like accessing a high-tech database through a retro computer terminal. Users should feel like they're browsing a futuristic fitness AI system.

VISUAL DESIGN:
- Background: Dark blue-black (#09131b) 
- Primary text: Bright cyan (#08f7fe)
- Font: Share Tech Mono (monospace) throughout entire site
- Add animated CRT-style scanlines moving vertically across the screen every 8 seconds
- All interactive elements should have subtle cyan glow effects on hover
- Style all content panels as terminal windows with terminal headers (3 colored dots: red, yellow, green)

LAYOUT & STRUCTURE:
- Header: Terminal-style with real-time clock, system status indicators, and integrated search bar
- Navigation: Collapsible sidebar styled as a terminal directory tree with 23+ fitness categories
- Main content: Grid of terminal-window cards OR interactive knowledge graph visualization
- Status bar: Bottom terminal status bar showing system info and current view mode
- All text should use terminal-style formatting with prefixes like "> ", "$ ", "• "

CONTENT STRUCTURE:
The site contains 574+ fitness and exercise science topics organized into categories:
- Foundation (66 topics): Exercise physiology, biomechanics, energy systems
- Resistance Training (71 topics): Training methods, programming, advanced techniques  
- Nutrition & Diet (107 topics): Sports nutrition, supplements, dietary strategies
- Exercise Library (100 topics): Detailed exercise instructions
- Performance Factors (35 topics): Testing, optimization, psychology
- Sports Specific (31 topics): Sport-specific applications
- Plus 17 additional specialized categories

INTERACTIVE FEATURES:
- Real-time search with command-line aesthetics
- Knowledge graph visualization showing interconnected topics as network nodes
- Topic cards displaying: title, quick summary, key points, reading time, citation count, difficulty level, related topics
- Breadcrumb navigation with terminal-style paths
- Grid view and graph view toggle buttons
- Hover states that enhance cyan glows and show connection lines

TOPIC CARD DESIGN:
Each topic should be presented as a terminal window containing:
- Terminal header with colored buttons and topic ID
- Quick takeaway (2-3 sentence summary)
- 3-5 key bullet points with terminal prefixes
- Metadata: reading time, citation count, difficulty level, last updated
- Tags with hashtag styling
- Related topics list with connection arrows
- "ACCESS TOPIC" button with terminal styling

TECHNICAL REQUIREMENTS:
- Fully responsive design maintaining cyberpunk aesthetic on mobile
- Smooth CSS animations for scanlines, glows, and transitions
- Search functionality with real-time filtering
- Category filtering and topic interconnection system
- Loading screens with terminal boot-up aesthetics
- Error states styled as terminal error messages

USER EXPERIENCE FLOW:
1. Landing page: Cyberpunk loading screen with "INITIALIZING FITNESS LIBRARY TERMINAL"
2. Dashboard: Overview with category selection and featured topics
3. Browse: Navigate through organized categories with visual hierarchy
4. Search: Command-line style search with auto-complete
5. Topic view: Detailed content with cross-references and related topics
6. Graph view: Interactive network visualization of topic relationships

CONTENT EXAMPLES:
Topics like "Progressive Overload", "Energy Balance", "Nutrition Timing", "VO2 Max Training" each containing academic-level content with research citations, practical applications, and safety considerations.

ANIMATIONS & EFFECTS:
- Continuous scanline effect across entire viewport
- Typing animations for text reveals
- Glow pulse effects on important elements
- Smooth transitions between views
- Matrix-style text reveals
- Terminal cursor blinking effects

Make this feel like a high-end fitness AI system from a sci-fi movie, where users are accessing the world's most comprehensive exercise science database through an advanced computer terminal.
```
